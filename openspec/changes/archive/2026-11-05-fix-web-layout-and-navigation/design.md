## Context
只读功能审查已完成，当前工作树存在用户未提交变更，实施前已保存 /tmp 基线。唯一写入 Agent 串行实施，其他 Agent 只读审查。
## Goals / Non-Goals
完成确认的权限、导航、摘要、编辑及错误恢复链路；不拆分全部编辑器，不用 Tabs 隐藏任务/节点/执行信息，不改变任务/调度/告警/联动业务边界。
## Decisions
- 精确查询增加可选 schedule_id，列表与 count 复用同一 WHERE；前端 node_id/schedule_id 纳入 URL、queryKey 与分页重置并可清除。
- 查看历史与编辑分区；编辑面板按需打开，切换/关闭/新建时确认丢弃脏数据，取消确认保留输入；保存失败保留草稿，删除清理当前选择。
- 应用操作使用已保存配置，存在配置草稿时先保存或放弃；不自动保存。节点选择保留已有语义。
- 共享 Main 宽度、详情单页和 Inventory 折叠保持；重复摘要合并，日志与截断提示保留。
- 管理员监控查询与渲染同时受角色限制。告警未汇总显示不可用，不显示占位健康。
- 常规行复用 RowText：主 14px/20px、副 12px/16px，2px 间距；身份/字段/动作 min-height 40px 并整体居中，保留自然增高。监控 bar/tags/数值徽章和日志/代码/表单保持语义。
- 只在任务与执行列表用现有 Card/CardContent 包工作区；标题与新建在卡外，scope/筛选/数据/分页/加载错空在内，移除空态内层卡；DataTable 不自动包卡。
- 品牌主行保留右侧 32px toggle，副文案独占下一行并自然换行；展开侧栏 15rem，折叠基础 3rem、移动 18rem不变，inset原边距保持。不调整登录说明或运行服务。
## Risks / Trade-offs
新增可选查询参数属于已确认公共 contract；旧请求不变。已有大规模修改不可回退，按基线核对交付范围。运行时验证使用独立临时数据服务，避免影响现有环境。
## Validation
API/store 混合调度与手动执行、空值/分页/count/组合过滤；Vitest Browser 行为回归、类型/lint/build；独立 QA 验证三角色、响应式、编辑取消恢复和深链。
