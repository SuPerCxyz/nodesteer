## Why
当前 Web 的角色入口、详情层级和表单切换存在可复现问题，导致无权限错误、重复信息与历史定位断链。本变更实现用户已确认的完整布局修复范围。
## What Changes
- 按角色显示监控，仪表盘自动化控制在上、监控概览在下且各占主内容区全宽，明确告警尚未汇总。
- 默认移除遗留历史卡并保留深链；按需编辑服务、联动、告警和传输，保护未保存输入。
- 精简任务/执行摘要，补调度/节点近期执行和准确筛选入口，提升应用操作与发布包入口。
- 设置失败重试，区分空态与错误；保留单页详情、日志和既有权限语义。
- 统一常规数据行主副文案层级、垂直对齐与最小内容高度；任务/执行列表各用一个页面 Card 包工作区，保留响应式和所有状态。
- 左上角品牌改为 Linux 节点自动化平台，桌面侧栏缩为 240px，保留完整副文案、移动/折叠尺寸与现有导航。
## Capabilities
### New Capabilities
无。
### Modified Capabilities
- `web-ui/layout`: 权限入口、详情层级、表单草稿保护与失败恢复。
- `hub/executions`: 可选 schedule_id 精确过滤，兼容原请求并组合 node_id。
## Impact
修改 Web 页面、现有执行查询 API/store 和定向测试。无 schema/迁移/依赖/CI/根配置变更；不改 AGENTS.md、不执行 Git 交付。
