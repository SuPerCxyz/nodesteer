## 0. 执行方式（每次按地图测试时照此执行）

1. 只读检查运行环境：`.e2e/run-state.json`、`coverage.json`、`workflows.json`、`failures.json`、`test-data.json`，确认上次断点、未测项与遗留数据。
2. 浏览器会话：`agent-browser --session e2e-<角色>`；RBAC 用独立会话（`e2e-viewer`/`e2e-operator`）。
3. 测试数据前缀：`e2e-<角色>-<YYYYMMDD>-<随机4位>`；只操作自己前缀的数据；结束清理并登记 `test-data`。
4. 证据：截图/控制台/网络写入 `.e2e/evidence/<角色>/`；每个结论必须有证据路径。
5. 失败项需可复现步骤；不可复现记为 observation；UI/UX 建议进 ui-review findings。
6. 完成后回填本文件第 4 节覆盖矩阵与 `.e2e/` 规范化文件；断点写入 `run-state.json`。

## 2. 实体与跨页联动

```text
Script ──被引用──> Task ──被引用──> Schedule
                    │ │
                    │ └── 目标: Node / Group(静态|标签) / Label ──> Node
                    └── Manual Run / Schedule Run ──> Execution ──> Node（stdout/stderr/exit）

Artifact ──被引用──> Application ──分配/部署──> Node
      （不可变,SHA256）      │                      └─ Managed systemd + Health Check
                             └──> Execution（deploy/upgrade/start/stop/restart）

Transfer: 源 Node 文件 ──上传校验──> Hub ──下载──> 目标 Node(s)（每目标独立状态）

User(Role) ──> 写权限；所有写操作 ──> Audit；Settings ──> Agent 同步行为
```

联动要点：
- L1 脚本编辑 → revision+1 → 引用它的任务 revision 变化 → 执行详情的 script_revision。
- L2 任务编辑 → 新 revision；被调度引用时禁止删除。
- L3 运行任务 → 执行记录（手动）；L4 调度触发 → 执行（trigger=schedule）；禁用后停止触发。
- L5 节点状态（在线/维护/禁用）影响任务运行与部署；L6 节点标签影响 label 目标任务；L7 分组（静态/标签）影响 group 目标任务。
- L8 发布包上传（独立页 or 应用内）→ 应用选择/关联；被应用引用时禁止删除。
- L9 应用部署 → 执行 + 节点侧 systemd/健康；L10 升级 → 版本/二进制更新（回滚若入口存在）。
- L11 文件传输多目标独立状态、重试/取消；L12 用户角色 → 菜单/按钮/接口权限；L13 设置保存 → 在线 Agent 同步；非法值拒绝。
- L14 所有写操作 → 审计；L15 删除受引用约束；L16 任务删除后执行历史保留（未知任务）；L17 取消运行中执行 → 进程终止；L18 语言/主题持久化。

## 3. 连续性主链（端到端验收）

1. 自动化链：脚本创建/编辑（revision）→ 任务（引用脚本，三种目标）→ 运行 → 执行详情 → 改脚本 → 任务 revision → 再运行 → 清理（删除被引用应阻止）。
2. 调度链：任务 → 调度（Cron/间隔/一次性，Agent/Hub 执行方）→ 触发 → 禁用 → 删除 → 删除任务 → 删除脚本。
3. 交付链：发布包（独立上传/应用内上传）→ 应用 → 分配 → 部署 → 执行 + 健康 → 升级 → 启停 → 删除应用 → 删除发布包；节点侧 systemd/二进制清理如实记录。
4. 目标链：label / 静态分组 / 标签分组 → 任务目标命中；分组删除后的行为。
5. 取消链：长任务 → 执行取消 → 状态取消 + 节点进程终止。
6. 传输链：源文件 → 多目标 → 内容校验；失败 → 重试/取消。
7. RBAC 链：创建 operator/viewer → 独立会话 → 菜单/按钮/直链/接口 403 → 回收。
8. 环境链：登录/仪表盘统计一致 → 各页搜索/过滤/分页 → 详情/返回 → 刷新保持。
